# Terms Of Service

Publisher: Reiner Weisssieker

Product: Azure Board Plugin Codex for Codex and ChatGPT-compatible MCP clients.

## Intended Use

The plugin provides decision support, governance review, approval planning, audit trail preparation, and Azure Boards workflow assistance. Generated reports, scores, recommendations, and Decision Packs are advisory artifacts and must be reviewed by authorized users before operational use.

## User Responsibilities

Users are responsible for ensuring they have permission to access the Azure DevOps organizations, projects, Work Items, comments, revisions, and evidence they provide to or retrieve through the plugin.

## Writes And Approvals

Write-capable Azure Boards workflows must remain behind explicit preview, selection, approval, and confirmation steps. Users are responsible for reviewing patches, comments, state changes, owner changes, relations, and audit rationale before applying them.

## Production Deployment

Production deployments must configure Microsoft Entra OAuth, hosted MCP transport, storage, logging, and secrets according to the deployment organization's security policy. Secrets must not be committed to source control or exported in generated artifacts.

## Limitations

The plugin does not replace legal, compliance, audit, financial, or project governance review. Outputs must be validated against authoritative business records and Azure DevOps state.
