# Support

For support with Azure Board Plugin Codex, use one of these channels:

- GitHub issues for reproducible bugs, documentation gaps, and feature requests.
- Email for security-sensitive or private reports: `rweisssieker@gmail.com`.

## Before Opening An Issue

Please include:

- Plugin version or commit.
- Operating system and Node.js version.
- Whether you are using local stdio MCP or hosted MCP.
- The command or workflow that failed.
- Redacted logs or error messages.
- Confirmation that no tokens, PATs, bearer values, device codes, or customer data are included.

## Production Deployment Support

Production deployment requires a real hosted MCP URL and a production Microsoft Entra app registration. Do not share secrets in public issues.
