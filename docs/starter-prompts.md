# Starter Prompts

These prompts are designed for marketplace onboarding and role-based demos.

## Product Owner

- Show my delivery risks, stale Requirements, and approval candidates from this Azure Boards query.
- Build an approval queue for the top recommendations and explain which ones are safe to apply.
- Export a Decision Pack with steering, audit, handover, and operating rhythm sections.

## Scrum Master

- Find stale, blocked, unowned, and aging work that needs action before the next standup.
- Compare this board against the Scrum policy pack and propose a cleanup queue.
- Simulate the impact of reducing WIP or removing blocked items before the next sprint review.

## CIO

- Create an executive steering room that maps board work to business value, outcome gaps, and decisions needed.
- Show which open work creates the most value leakage, compliance risk, or cutover risk.
- Build an outcome proof report that compares expected benefits with realized evidence.

## Compliance

- Score compliance evidence completeness and show missing approvals, owners, and audit artifacts.
- Create an audit trail from accepted, rejected, overridden, and recorded recommendations.
- Export an Audit Pack that includes evidence, rationale, actor, timestamp, and verification status.

## Release Manager

- Validate this release against the release-governance policy pack and show go/no-go blockers.
- Create a safe apply plan for release cleanup recommendations.
- Review apply results against expected changes and produce audit events.

## Admin

- Show production admin settings for policy thresholds, risk weights, data classes, and LLM mode.
- Review AI readiness, prompt governance, model risk, and evaluation cases before rollout.
- List built-in policy packs and recommend which one fits this role and scenario.
