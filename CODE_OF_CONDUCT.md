# Code Of Conduct

## Our Pledge

Participants are expected to keep project discussions respectful, constructive, and focused on improving Azure Board Plugin Codex.

## Expected Behavior

- Use welcoming and professional language.
- Respect different viewpoints and experience levels.
- Focus feedback on code, documentation, design, security, and user impact.
- Avoid sharing private customer data, secrets, or confidential board content.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private information without permission.
- Posting secrets, tokens, customer data, or private board exports.
- Disruptive behavior that prevents productive project work.

## Enforcement

Maintainers may remove comments, close issues, block users, or take other reasonable action when behavior violates this code of conduct.
